# Claude Skills

Coleção pessoal de [skills](https://docs.claude.com/en/docs/agents-and-tools/agent-skills/overview) do Claude, usadas no dia a dia como desenvolvedor.

## Skills

| Skill | Descrição |
|---|---|
| [`code-review`](./code-review) | Revisa código (diff/PR ou trecho), combinando boas práticas gerais com checklist pessoal. Saída em resumo estruturado por categoria. |
| [`preferencia-de-codigo`](./preferencia-de-codigo) | Aplica convenções de estilo pessoais para TypeScript, React e Node.js — tipagem, estrutura de componentes, hooks, controle de fluxo. |
| [`documentacao-funcional`](./documentacao-funcional) | Gera documentação funcional (specs/requisitos ou fluxos de negócio existentes) no formato de user stories com critérios de aceite. |
| [`documentacao-tecnica`](./documentacao-tecnica) | Gera documentação técnica focada em runbooks — procedimentos operacionais enxutos e diretos. |
| [`planejamento-de-tarefa`](./planejamento-de-tarefa) | Quebra uma tarefa de desenvolvimento em plano técnico estruturado antes de codar: contexto, regras, passos, testes, layout e riscos. |
| [`resumo-de-tarefa`](./resumo-de-tarefa) | Gera resumo do que foi corrigido/implementado numa tarefa, pronto para colar em ticket/PR — versão completa e resumida. |

## Como instalar

Cada pasta contém um `SKILL.md`. Para usar no Claude.ai, Claude Code ou Cowork, siga as instruções de instalação de skills da [documentação oficial](https://docs.claude.com/en/docs/agents-and-tools/agent-skills/overview).
